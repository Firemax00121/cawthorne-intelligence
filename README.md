# Cawthorne Intelligence

Public website repository for Cawthorne Intelligence.

## Publishing policy

Public pages may contain verified public-market facts and clearly identified research status. Do not publish invented benchmark prices, internal commercial assumptions, unpublished methodology, contributor thresholds, proprietary weighting, normalization rules, scoring logic or private institutional terms.

Institutional inquiries: info@cawthorneintelligence.com

## Deployment

GitHub Pages deployment is handled by `.github/workflows/deploy.yml` after Pages is configured to use GitHub Actions.
